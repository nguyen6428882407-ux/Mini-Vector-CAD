Phân Tích Kiến Trúc Dự Án Mini Vector CAD & Thiết Kế UML (Task 22)

Tài liệu bàn giao: Task 22 - Thiết kế sơ đồ lớp UML (Class Diagram) & Phân tích luồng hoạt động hệ thống.

Dự án: Mini Vector CAD (C++17, CLI & Web/C++ Server).

Mục tiêu: Mô tả cấu trúc tĩnh, mối quan hệ giữa các thực thể cốt lõi và các luồng hoạt động (Activity / Sequence) của hệ thống.

1. Phân Tích Tổng Quan Dự Án & Kiến Trúc Phần Mềm

1.1. Mục tiêu và phạm vi hệ thống

Mini Vector CAD là ứng dụng đồ họa vector 2D được viết bằng C++17, hỗ trợ quản lý bản vẽ theo nhiều lớp (layers), vẽ và biến đổi các hình học cơ bản/phức tạp, cơ chế Hoàn tác/Làm lại (Undo/Redo), xuất/nhập file văn bản thuần (.txt) và đồ họa vector chuẩn SVG. Hệ thống cung cấp hai môi trường hoạt động:

  1. Giao diện dòng lệnh tương tác (CLI): Điều phối bởi MenuController phục vụ người dùng console.
  2. Giao diện Web & C++ Backend Server: Kết nối qua HTTP Socket Server cục bộ (ProjectServer), tích hợp hệ thống xác thực người dùng (UserManager) và quản lý dự án bản vẽ (ProjectManager).

1.2. Các Design Pattern Cốt Lõi Được Áp Dụng

Design Pattern Lớp tham gia Mục đích và vai trò trong hệ thống
Composite Pattern HinhHoc2D (Component), GroupShape (Composite), HinhTron, DoanThang, HinhChuNhat, TamGiac, DaGiac, NetVeTuDo (Leafs) Xử lý hình đơn lẻ và nhóm hình phức hợp một cách đồng nhất. GroupShape có thể chứa các hình đơn hoặc các GroupShape con lồng nhau vô hạn theo cấu trúc cây (Tree structure). Khi gọi tính diện tích, chu vi, biến đổi, vẽ, hệ thống tự động đệ quy xuống các nút lá.
Prototype Pattern HinhHoc2D::clone(), các lớp hình cụ thể Cung cấp khả năng sao chép sâu (deep copy) đối tượng hình học mà không cần biết kiểu cụ thể. Điểm đặc biệt của hệ thống: clone() sao chép kiểu dáng (stroke, fill, nét) nhưng cấp phát ID duy nhất mới, bảo đảm bất biến tính toàn vẹn định danh.
Command Pattern Command (Interface), CommandManager (Invoker), AddShapeCommand, RemoveShapeCommand, TransformCommand, GroupCommand (Concrete Commands), BangVeCanvas (Receiver) Đóng gói mọi thao tác thay đổi bản vẽ thành đối tượng lệnh có khả năng thực thi (execute()) và hoàn tác (undo()). Sử dụng 2 ngăn xếp undoStack_ và redoStack_. Hỗ trợ rollback chính xác mà vẫn bảo toàn ID gốc để không làm gãy chuỗi lệnh phía sau.
Simple Factory / Factory Method ShapeFactory Phân tích chuỗi mô tả (từ CLI hoặc file TXT) để sinh đối tượng hình học tương ứng (tron, doanthang, chunhat, tamgiac, dagiac, brush), tách biệt hoàn toàn logic khởi tạo và kiểm tra dữ liệu đầu vào khỏi các lớp nghiệp vụ.

2.1. Phân Tích Chi Tiết Quan Hệ Giữa Các Thực Thể

  1. Quan hệ Kế thừa (Inheritance / Generalization <|--):

    Các lớp hình học cụ thể (DoanThang, HinhTron, HinhChuNhat, TamGiac, DaGiac, NetVeTuDo, GroupShape) kế thừa từ lớp trừu tượng HinhHoc2D. Tất cả đều phải ghi đè các hàm thuần ảo: tam(), tinhDienTich(), tinhChuVi(), transform(), clone(), ve(), toSVG(). Tương tự, các lệnh thao tác kế thừa từ lớp giao diện thuần ảo Command (execute() và undo()).

  2. Quan hệ Hợp thành & Chứa đựng (Composition *-- & Aggregation o--):

    BangVeCanvas *-- Layer: Một bản vẽ chứa tập hợp tuần tự các Layer. Khi Canvas bị hủy, toàn bộ Layer cũng bị hủy. GroupShape o-- HinhHoc2D: Mắt xích cốt lõi của Composite Pattern, cho phép một GroupShape nắm giữ các hình đơn hoặc GroupShape khác lồng nhau vô hạn.

  3. Quan hệ Phụ thuộc & Hiệp tác (Dependency ..> & Association -->):

    Command chỉ giữ tham chiếu BangVeCanvas& (không sở hữu vòng đời) và xác định đối tượng qua (layerIdx, id) để tránh dangling pointer khi Undo/Redo. TransformCommand giữ ma trận thuận và ma trận nghịch đảo $M^{-1}$ để khôi phục trạng thái tức thời.

4. Bảng Đối Chiếu Các Thực Thể & Trách Nhiệm Thiết Kế

Tầng kiến trúc Lớp / Cấu trúc Kiểu thực thể Trách nhiệm chính trong hệ thống
Core Diem2D Value Object Tọa độ điểm 2D (x, y), các phép toán vector (+, -, *) và tính khoảng cách Euclid.
MauSac Value Object Màu RGBA với độ trong suốt alpha, chuyển đổi chuỗi mã màu hex (#RRGGBBAA).
BienDoi2D Value Object Ma trận affine 3x3, tạo phép tịnh tiến, xoay quanh tâm, tỉ lệ đều và tính ma trận nghịch đảo.
Shapes HinhHoc2D Abstract Component Định nghĩa giao diện chung cho mọi hình học; quản lý ID duy nhất toàn cục, màu viền, màu nền, độ dày nét; hỗ trợ clone() và toSVG().
DoanThang Concrete Leaf Biểu diễn đoạn thẳng giữa 2 điểm. Diện tích = 0.
HinhTron Concrete Leaf Biểu diễn hình tròn với tâm và bán kính; scale giữ nguyên tỉ lệ tròn.
HinhChuNhat Concrete Leaf Hình chữ nhật xác định qua 4 đỉnh; hỗ trợ tính tâm hộp bao và xoay affine tự do.
TamGiac Concrete Leaf Tam giác xác định bởi 3 điểm; tính diện tích bằng giải thuật vector chéo.
DaGiac Concrete Leaf Đa giác khép kín n đỉnh; tính diện tích Shoelace và tâm bounding box.
NetVeTuDo Concrete Leaf Chuỗi các điểm di chuột liên tục; phục vụ vẽ tự do / bút chì.
GroupShape Composite Gom nhóm nhiều đối tượng HinhHoc2D con; chuyển tiếp đệ quy các lệnh tính toán và biến đổi.
ShapeFactory Factory Phân tích cú pháp chuỗi câu lệnh để khởi tạo đối tượng hình học tương ứng.
Canvas Layer Entity Container Quản lý tập hợp hình vẽ trong một lớp; hỗ trợ ẩn/hiện, khóa/mở khóa chỉnh sửa.
BangVeCanvas Aggregate Root Quản lý toàn bộ danh sách các Layer, kích thước bản vẽ (w x h) và layer hoạt động hiện tại.
Commands Command Abstract Command Định nghĩa hợp đồng execute() và undo().
AddShapeCommand Concrete Command Thêm hình vào layer; undo sẽ rút hình ra cất lại.
RemoveShapeCommand Concrete Command Xóa hình khỏi layer; undo sẽ hoàn trả hình vào đúng chỉ số vị trí cũ.
TransformCommand Concrete Command Biến đổi hình bằng ma trận M; undo bằng cách áp dụng ma trận nghịch đảo M^-1.
GroupCommand Concrete Command Gom các hình con thành GroupShape; undo sẽ giải tán nhóm và trả lại các hình con.
CommandManager Invoker Điều khiển 2 ngăn xếp undoStack_ và redoStack_, giới hạn kích thước lịch sử.
Controller & I/O MenuController Controller Nhận lệnh console, kiểm tra điều kiện nghiệp vụ và gọi CommandManager.
SvgExporter Service / Exporter Xuất toàn bộ cấu trúc bản vẽ ra chuẩn định dạng XML SVG.
TextSerializer Service / Serializer Tuần tự hóa bản vẽ ra định dạng text .txt để lưu trữ bền vững và giải tuần tự khi nạp.
Web & Auth ProjectServer HTTP Server Socket server lắng nghe cổng 8766, điều hướng các REST endpoint cho Web GUI.
UserManager Service Băm mật khẩu (SHA-256 + Salt), cấp phát và kiểm tra token phiên làm việc.
ProjectManager Repository / Service Quản lý dự án đa người dùng, cấp quyền cộng tác viên và lưu file dự án.
