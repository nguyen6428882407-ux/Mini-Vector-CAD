sequenceDiagram
    autonumber
    actor User as Người dùng
    participant MC as MenuController
    participant SF as ShapeFactory
    participant CM as CommandManager
    participant CMD as AddShapeCommand
    participant Canvas as BangVeCanvas
    participant Layer as Layer

    Note over User,Layer: Giai đoạn 1: Thêm hình vẽ mới
    User->>MC: Nhập lệnh (VD: "tron 400 300 60 vien 255 0 0 net 2")
    MC->>SF: taoHinh(chuỗi mô tả)
    SF->>SF: Parse tham số, kiểm tra hợp lệ
    SF-->>MC: Trả về std::unique_ptr (id=1)
    
    MC->>CMD: Khởi tạo AddShapeCommand(canvas, layerIdx=0, hinh)
    MC->>CM: thucThi(std::move(cmd))
    activate CM
    CM->>CMD: execute()
    activate CMD
    CMD->>Canvas: layer(0)
    Canvas-->>CMD: Layer&
    CMD->>Layer: themHinh(std::move(hinh_))
    deactivate CMD
    CM->>CM: Xóa sạch redoStack_
    CM->>CM: Đẩy lệnh vào undoStack_
    CM-->>MC: Hoàn tất
    deactivate CM
    MC-->>User: Thông báo: "Thêm hình thành công!"

    Note over User,Layer: Giai đoạn 2: Hoàn tác lệnh vừa thêm (Undo)
    User->>MC: Chọn menu 6 (Undo)
    MC->>CM: undo()
    activate CM
    CM->>CM: Pop lệnh đỉnh undoStack_
    CM->>CMD: undo()
    activate CMD
    CMD->>Canvas: layer(0)
    Canvas-->>CMD: Layer&
    CMD->>Layer: layHinh(id=1)
    Layer-->>CMD: Trả về unique_ptr (chuyển giao lại quyền sở hữu)
    CMD->>CMD: Cất lại vào biến thành viên hinh_ (giữ nguyên ID=1)
    deactivate CMD
    CM->>CM: Đẩy lệnh sang redoStack_
    CM-->>MC: Trả về true
    deactivate CM
    MC-->>User: Thông báo: "Đã hoàn tác: hình #1 biến mất"

    Note over User,Layer: Giai đoạn 3: Làm lại lệnh (Redo)
    User->>MC: Chọn menu 7 (Redo)
    MC->>CM: redo()
    activate CM
    CM->>CM: Pop lệnh đỉnh redoStack_
    CM->>CMD: execute()
    activate CMD
    CMD->>Canvas: layer(0)
    Canvas-->>CMD: Layer&
    CMD->>Layer: themHinh(std::move(hinh_))
    Note right of Layer: Hình được khôi phục vào đúng vị trí với ID nguyên bản
    deactivate CMD
    CM->>CM: Đẩy lệnh trở lại undoStack_

Luồng Biến Đổi Affine & Ma Trận Nghịch Đảo
Tính toán ma trận thuận và nghịch đảo M^-1 để hoàn tác chính xác.
sequenceDiagram
    autonumber
    actor User as Người dùng
    participant MC as MenuController
    participant BD as BienDoi2D
    participant TC as TransformCommand
    participant CM as CommandManager
    participant Shape as HinhHoc2D (Leaf / Group)

    User->>MC: Yêu cầu biến đổi hình (ID, Phép toán: Scale k=1.5 quanh tâm)
    MC->>MC: Tìm hình theo ID, lấy tâm hình tam = shape->tam()
    MC->>BD: tiLeDeu(k=1.5, tam)
    BD-->>MC: Ma trận biến đổi M
    MC->>TC: Tạo TransformCommand(canvas, layerIdx, id, M)
    activate TC
    TC->>BD: M.nghichDao()
    Note over TC,BD: Tính toán trước ma trận nghịch đảo M_inv = M^-1
    BD-->>TC: Trả về ma trận nghịch đảo M_inv
    deactivate TC

    MC->>CM: thucThi(std::move(transformCmd))
    CM->>TC: execute()
    TC->>Shape: transform(M)
    Note over Shape: Điểm/tọa độ được cập nhật: P' = M * P
    TC-->>CM: Hoàn thành

    opt Người dùng Undo biến đổi
        User->>MC: Chọn Undo
        MC->>CM: undo()
        CM->>TC: undo()
        TC->>Shape: transform(M_inv)
        Note over Shape: Áp dụng M_inv: P = M_inv * P' -> Trở về trạng thái ban đầu chính xác
    end
Luồng Gom Nhóm / Rã Nhóm Hình Vẽ (Composite)
Quản lý đóng gói cây đối tượng và hoàn trả danh sách con.
sequenceDiagram
    autonumber
    actor User as Người dùng
    participant MC as MenuController
    participant GC as GroupCommand
    participant CM as CommandManager
    participant Layer as Layer
    participant GS as GroupShape

    User->>MC: Chọn gom nhóm các hình có ID: [2, 5, 8]
    MC->>MC: Kiểm tra tính hợp lệ (các ID tồn tại trong Layer, layer không khóa)
    MC->>GC: Tạo GroupCommand(canvas, layerIdx, shapeIds=[2, 5, 8], Loai::GOM)
    MC->>CM: thucThi(std::move(groupCmd))

    activate GC
    CM->>GC: execute()
    GC->>GS: Khởi tạo GroupShape mới (sinh GroupId mới, vd: #10)
    loop Với từng id trong [2, 5, 8]
        GC->>Layer: layHinh(id)
        Layer-->>GC: std::unique_ptr
        GC->>GS: themHinh(std::move(hinhCon))
    end
    GC->>Layer: themHinh(std::move(group_)) vào vị trí của hình con đầu tiên
    deactivate GC
    CM-->>MC: Gom nhóm hoàn tất

    opt Người dùng Undo Gom Nhóm
        User->>MC: Chọn Undo
        MC->>CM: undo()
        CM->>GC: undo()
        activate GC
        GC->>Layer: layHinh(groupId=10)
        Layer-->>GC: unique_ptr
        loop Rút các hình con ra khỏi GroupShape
            GC->>GS: rutHinh(id)
            GS-->>GC: unique_ptr
            GC->>Layer: themHinh(hinhCon, viTriCu)
        end
        Note over Layer: Khôi phục lại đúng vị trí và thứ tự Z-index ban đầu của các hình con
        deactivate GC
    end
Luồng Đồng Bộ Web Frontend & C++ Socket Server
Giao thức HTTP REST và đồng bộ stream bản vẽ TextSerializer.
sequenceDiagram
    autonumber
    actor Browser as Trình duyệt (Web GUI)
    participant Server as ProjectServer (C++ Socket 8766)
    participant PM as ProjectManager
    participant UM as UserManager
    participant Canvas as BangVeCanvas
    participant TS as TextSerializer

    Note over Browser,TS: Đăng nhập & Lấy phiên làm việc
    Browser->>Server: POST /api/login { username, password }
    Server->>UM: loginUser(username, password)
    UM-->>Server: Token hợp lệ + UserAccount
    Server-->>Browser: HTTP 200 { token, username, fullName }

    Note over Browser,TS: Mở dự án & Tải bản vẽ
    Browser->>Server: GET /api/projects/:id (Header: Authorization Bearer token)
    Server->>UM: validateToken(token)
    UM-->>Server: User hợp lệ
    Server->>PM: getProject(projectId)
    PM->>PM: Kiểm tra quyền truy cập (owner hoặc member)
    PM-->>Server: ProjectItem (chứa BangVeCanvas)
    Server->>TS: serialize(canvas, stream)
    TS-->>Server: Dữ liệu văn bản bản vẽ (TXT format)
    Server-->>Browser: HTTP 200 { id, name, revision, canvasText }

    Note over Browser,TS: Người dùng vẽ trên Web & Đồng bộ lại Server
    Browser->>Browser: Người dùng thao tác vẽ/chỉnh sửa trên HTML5 Canvas
    Browser->>Server: POST /api/projects/:id/sync { token, canvasText }
    Server->>UM: validateToken(token)
    Server->>PM: getProject(projectId)
    Server->>TS: deserialize(project->canvas, stream)
    TS->>Canvas: Tái tạo toàn bộ danh sách Layer & HinhHoc2D
    Server->>PM: saveProjectCanvas(project)
    PM->>PM: Ghi file lưu trữ đĩa (output/projects/:id.txt)
    Server-->>Browser: HTTP 200 { status: "ok", revision: ++rev }
